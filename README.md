# Volley World

Una guía visual para descubrir el voleibol: cómo se juega, qué ocurre en la pista y qué aporta cada posición.

El proyecto es un sitio estático, adaptable a móviles y creado con HTML, CSS y JavaScript vanilla. No requiere frameworks, instalación de paquetes ni proceso de compilación.

## Contenido

- **Portada** con navegación, presentación del deporte y enlaces a las secciones principales.
- **Guía de juego** con reglas, puntuación, rotación, posiciones y un esquema de la pista.
- **Galería de 14 tarjetas**, filtrable por técnicas, equipo y roles, y modalidades.
- **Contacto** con un borrador de correo que se puede editar antes de enviar.



## Archivos principales

| Archivo | Descripción |
| --- | --- |
| `index.html` | Portada, navegación, galería y contacto. |
| `guia.html` | Reglas, puntuación, rotación y posiciones. |
| `styles.css` | Estilos y diseño adaptable para ambas páginas. |
| `script.js` | Menú móvil, animaciones de entrada y filtros de galería. |


## Imágenes y recursos

Las imágenes de la galería enlazan a sus fuentes y muestran sus créditos y licencias. La fotografía principal y las fuentes tipográficas se cargan desde servicios externos; hace falta conexión a internet para ver esos recursos.
